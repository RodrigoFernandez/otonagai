# otonagai
Otonagai (大人買い): Es un término cultural japonés espectacular. Significa "comprar como un adulto", y se usa específicamente cuando un adulto usa su sueldo para comprar juguetes, mangas o coleccionables que de chico no podía permitirse. Es ideal si tu aplicación se enfoca mucho en el registro de precios y presupuesto de compra.
